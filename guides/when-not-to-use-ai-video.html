Guides

When not to use AI video

A product video for a printed t-shirt. Slow push-in on the chest graphic. Three seconds. It should have been the easiest thing I'd asked a video model to do, and it was the only job I've had to abandon outright.

What went wrong

Every image-to-video run morphed the print. The artwork breathed, letters bent, the design drifted between frames. Not once — every run. Different prompts, different seeds, same failure.

The reason is structural, and worth understanding because it generalises. A generative video model re-imagines every frame. It has no concept of "this region is a fixed asset that must remain pixel-exact." A face it re-imagines slightly differently reads as a person moving — that's the magic. A logo it re-imagines slightly differently reads as broken, because we know exactly what a logo is supposed to look like. The tolerance for invention is near-zero on designed artifacts and generously high on faces.

What I built instead

I stopped generating that shot and composited it deterministically in code:

  • Resample the garment photo per frame with a floating crop box — that's the Ken Burns push-in, done arithmetically.
  • Resample the real print file (the actual 3461×3955 production artwork) straight into each frame at output resolution, shaded by the fabric's luminance so it sits on the cloth.
  • Titles, wipes and cards as image overlays. Export silent H.264 at 30fps; audio at post.

The print is now pixel-exact at every zoom level — including a tight close-up — and cannot warp, because at no point does a model get an opinion about it. Marginal cost: $0. Reruns are byte-identical.

The rule I kept

Generative video for faces, bodies and motion. Code for anything that has to stay exactly itself — logos, printed artwork, legible text, UI, charts, product packaging.

Follow it and you get a useful side effect: verifiability. I can render a frame through the code path and compare it against the approved proof numerically. There is no equivalent check for "did the model respect my logo this time" except looking, every time, forever.

How to tell which side of the line you're on

One question: is there a correct answer to what this pixel region should look like?

  • Yes — a logo, a label, a price, a screenshot, a chart. Composite it. Don't generate it.
  • No — hair movement, fabric drape, a turn of the head, a camera drift through a room. Generate it. This is what the models are genuinely great at.

Most short-form content is a mix, and the mixed answer is a mixed pipeline. The screen recordings in my own videos are there for exactly this reason: a real capture of a real interface is both more honest and more reliable than any generated approximation of one.
